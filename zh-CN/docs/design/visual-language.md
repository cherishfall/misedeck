# 视觉语言

> [English](../../docs/design/visual-language.md)

MiseDeck 界面的设计系统基础。由 #33 设计冲刺产出（原型见 `docs/design/tools-page.prototype.html`，截图在同目录），由 #20 落地为 token 与组件。所有 UI 工单的颜色、字体、动效都从这里推导——不允许临时发明。

## 原则

 1. **忠实的 HUD。** 简报（#9）：科幻电影 HUD——冷色辉光、半透明面板、发光线条——以 Linear 级别的精致度执行。参考融合方向是贾维斯（电光青 + 琥珀全息），不是霓虹赛博海报。
2. **等宽字体是数据的声音。** 版本号、路径、命令、日志、标签全部使用等宽字体并带辉光——数据本身就是界面的装饰。展示字体保持安静。
3. **签名元素只用一处。** 信号线（见下）是唯一让人记住的元素。它周围的一切保持克制：平面、1px 边线、有限的辉光。
4. **从第一天就是双主题。** 暗色是主基调；浅色是设计过的对应版本（"白昼全息"），不是简单反色。两者共用同一套 token 槽位。

## 色彩

所有颜色都是 CSS 自定义属性；组件只消费语义化名称。暗色值为默认；浅色覆盖写在 `[data-theme="light"]` 下。

| Token | 暗色 | 浅色 | 职责 |
|---|---|---|---|
| `--void` | `#04070C` | `#EDF2F7` | 应用背景 |
| `--hull` | `#0A1220` | `#FFFFFF` | 面板底色 |
| `--beam` | `#3BE2FF` | `#0B8FB8` | 主信号——激活态、焦点、关键数据 |
| `--ice` | `#7FB3E8` | `#4A6FA5` | 次要信息——backend、日志前缀、链接 |
| `--flare` | `#FFB454` | `#B45309` | 注意——过期版本、警告 |
| `--breach` | `#FF5470` | `#D63B5C` | 危险操作 / 错误 |
| `--text` | `#DCE9F5` | `#0F1C2B` | 主文字 |
| `--dim` | `#5F748C` | `#64748B` | 次要文字、非激活图标 |

派生值（用 `color-mix` 从上面的 token 计算，禁止硬编码）：

- `--panel`：`hull` 72% 不透明度——应用背景之上的面板填充
- `--line`：`beam` 16%——默认边线与分隔线
- `--line-strong`：`beam` 40%——强调边线（执行舱、主按钮）
- `--beam-soft`：`beam` 60%——辉光边缘、激活强调

语义纪律：

- **beam** 标记*当前状态*（激活版本、选中导航、焦点）。
- **flare** 标记*可行动的漂移*（有更新版本、警告）。过期永远渲染为升级路径 `22.11.0 ▹ 22.20.0`，绝不只靠颜色表达。
- **breach** 只用于危险操作和真实错误。
- 文字辉光（`text-shadow` 取 token 的 30–45%）只给发光数据：版本号、页面标题、命令回显。正文永远不发光。

## 字体

| 角色 | 字体 | 用法 |
|---|---|---|
| 展示 | Space Grotesk 600，收紧字距 | 页面标题（大写，letter-spacing ≈ .14em）、wordmark（letter-spacing ≈ .32em） |
| 界面 / 导航 | Space Grotesk 400–500 | 导航项、按钮、正文 |
| 数据 | JetBrains Mono 400–600 | 版本号、路径、命令、日志、徽标、区块标签（大写，letter-spacing ≈ .18–.24em） |

- 中文回落到 `PingFang SC` / `system-ui`（展示与界面角色）；拉丁数据（版本号、命令）保持 JetBrains Mono。
- 基准字号 14px，数据 11–13px，区块标签 10–10.5px。不用流式字号；保持桌面应用密度。
- 区块眉标读作 HUD 面包屑：`▸ MANAGE / TOOLS`。

## 布局

```
┌──────────────────────────────────────────────┐
│ wordmark · 目录上下文 · 状态徽章              │  上下文条，52px
├──────────┬───────────────────────────────────┤
│ 导航     │  页头（眉标、标题、元信息）          │
│ 196px    │  面板                              │
├──────────┴───────────────────────────────────┤
│ 执行舱——命令回显 + 实时日志                    │  停靠底部
└──────────────────────────────────────────────┘
```

- **执行舱**停靠在每个页面底部——产品的签名行为（所有变更操作都回显真实的 `mise` 命令并流式展示输出）。
- 面板：`--panel` 填充、1px `--line` 边线、8px 圆角、`backdrop-filter` 模糊。**角标框线**（2px `--beam-soft` 直角，左上 + 右下）只框住页面的主面板——每屏一个。
- 间距走 4px 网格；常用间距 14 / 16 / 22 / 26px。
- 唯一的背景装饰：向底部渐隐的淡点阵，加顶部一处柔和径向辉光。内容上不铺渐变、不加噪点纹理。

## 签名元素：信号线

一条 1px 发光线（`--line` 基底）载着缓慢扫过的高光（`--beam` 渐变扫光，约 6s 线性循环）——一条贯穿界面的数据总线。它锚定：上下文条下沿、执行舱上沿、激活面板。配合执行舱里闪烁的光标，构成简报要求的"数据流"感。

规则：只用水平线或 2px 竖向边缘刻度；从不斜向，每个表面最多一条扫光，从不与其他动画装饰叠加。

## 动效

系统里只有三种常驻动效：

1. 信号线扫光（约 6s 线性）。
2. `flare` 状态点的注意脉冲（柔和的不透明度/缩放呼吸）。
3. 日志光标闪烁（约 1.1s 步进）。

其余全部是 ≤120ms ease-out 的状态过渡（悬停、面板滑入）。`prefers-reduced-motion` 下所有动效关闭。如果某个界面需要第四种动画，错的是设计，不是规则。

## 护栏（防止滑向千篇一律的 AI 暗色风）

- 不要酸绿配纯黑，不要紫粉霓虹渐变，不要玻璃拟态堆叠。
- 不要科幻展示字体（Orbitron 之类）；个性来自等宽数据 + 字距，而不是张牙舞爪的字形。
- 不要装饰性编号（01/02/03），不要 emoji 图标；图形符号用几何形（▸ ◈ ≡ ▹）。
- 浅色主题保留 HUD 语法（角标、等宽数据、宽字距标签），落在冷白纸底上——不是白色企业风换皮。
