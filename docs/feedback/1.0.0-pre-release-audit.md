# 1.0.0 pre-release audit (scratch)

> Working doc for the comprehensive pre-1.0.0 GA review. Owner-authorized dimensions: code, docs, features, UI, interaction, typography — **plus visual verification and simulation verification** (beta9 no-visual-verification rule explicitly lifted for this cycle).
>
> Baseline: master @ `37d27fb` (v1.0.0-beta.17 shipped), clean tree.
> Baseline checks: `npm run ci` green (typecheck + 133 unit tests + 12 lint guards + build); `cargo test --all-targets` green.

> This file is exempt from zh-CN mirroring (docs/feedback/ working doc).

## Severity scale

- **P0** — blocks the 1.0.0 release (data loss, crash, fabricated output, silent failure on a core path)
- **P1** — must fix before 1.0.0 GA (wrong/frustrating behavior a first-time user hits in the first session)
- **P2** — fix if cheap, or flag for an owner decision (polish, rare edge, cosmetic)
- **OK** — audited clean (reported per the proactive-sweep agreement)

## Findings — P2 (not decided for GA yet)

### Rust

- `app_update_check_failed` is a seventh error code outside the fixed set, pinned by a wire test → use `COMMAND_FAILED`.
- ~50 `AppError.message` values are pre-rendered English instead of `key|param=`; three UI sites display them raw.
- `activated: null` (undeterminable) is treated as false by `if (status.activated)` → renders as "activation missing".
- `cancelled` set grows unbounded on cancel-vs-finished races.
- Post-self-update version probe uses the streaming path (no MISE_SAFE, 30-min ceiling) instead of the read path (10s).
- Whole rc file shipped over IPC on every launch, never read by the frontend (same class as beta.17's unused-field finding).
- `check_trust` silently fails open to `NoConfig` on unrecognized output → trust gate removed.
- Windows: `taskkill`/`curl.exe`/`powershell`/`cmd.exe` resolved via PATH/cwd (binary planting surface) → use `%SystemRoot%\System32\…`.
- "Empty version = latest" contradicts mise help (bare name installs the config-requested version).
- Real argv is duplicated in TS; the Rust builder is test-only, synced by comments.
- `mise doctor --json` non-zero exit triggers a second text run (comment contradicts behavior, doubles time).
- Update feed uses `Command::output` with no byte cap.
- `validated_cwd` does blocking `is_dir()` on an async worker.
- Coverage gaps: `run_install`, `update::check`, `detect_user_shell`, lockfile upward search, MISE_SAFE.
- `errors.terminalNotFound` copy (same as I-1).

### Frontend

- `detect_mise` rejection leaves Home spinning "Detecting mise…" forever (no `isError` branch).
- Activation-probe error state is produced but never rendered (Doctor row).
- Trust-probe error blocks every write with no retry; refresh never invalidates the trust key.
- `ExternalLink` swallows opener failure (the #249 class: Release/Download dead-ends silently).
- `set_window_theme` failure silent.
- Failed `cancel_run` leaves the panel claiming "cancelled" while the process keeps running.
- Unguarded `localStorage` at boot above the error boundary → possible empty window.
- No catch-all route: unknown path renders a window with no chrome.
- Run switcher declares `tablist`/`tab` without `aria-controls`/`tabpanel`/roving tabindex/arrow keys.
- Filter/Env/Settings inputs suppress the global focus ring, leaving a 1px border only.
- Directory probe `unknown` computed and dropped → one stderr block per page.
- ~20 exports with no cross-file consumer; two orphan SVGs + `/vite.svg` as favicon; hardcoded English tooltip in `AddToolSection.tsx:540`; `U+2192` outside every bundled face's `unicode-range`; bundled OFL fonts ship without licence text; `shortenPathTail` budgets UTF-16 units (CJK paths lose the segment it preserves); Tooltip wrapper makes every data cell a tab stop; panel resize grip pointer-only; `DataRow` `dt`/`dd` outside `<dl>`; clipboard fallback steals focus; two dead tokens; no ESLint (nothing guards rules-of-hooks/exhaustive-deps).

## Post-fix re-verification (GA)

Date: 2026-10-22. Build under test: `master` at `95efe48` plus the 1.0.0 release diff (version bump, README/CONTEXT updates, new screenshots), before the release commit. The app reports `1.0.0` in all six version sites.

Method: a temporary `misedeck/src/__shotSeed.ts`, imported first in `main.tsx`, seeded `misedeck.language` / `misedeck.theme` and used `history.replaceState` to pick the route; each launch consumed one entry, and one extra launch cleared the harness keys and restored the previous preferences. The app was built with `npm run tauri build -- --debug --bundles app`, launched under `env -i` with a controlled `HOME` and `PATH`, located through the Quartz window list (system Python), and captured window-only with `screencapture -x -o -l <window id>`. No `tauri dev`, no TCC prompt, and no OS permission was granted. The seed file and the `main.tsx` import were removed before committing, and `tauri.conf.json` was restored to 1200×720 after the README pass.

### Observations

- The unparsable-version card on Home has no inline Retry; the toolbar Refresh is the recovery affordance. This matches the pre-fix behaviour and is recorded so the state is not silent.
- In the contrived Tools-failure fixture the outdated probe still returned `{}`, so the hint read "All installed tools are up to date." while the list card showed the failure. The two queries are independent; a real mise failure would generally fail both. Not treated as a finding.
